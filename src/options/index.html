Settings

Choose where CORS response headers are relaxed and which requests are excluded.

Behavior

Control when the extension modifies responses.

Scope

Global mode relaxes CORS headers for every website, not just your active rules. Switch to Whitelist when you are done debugging.

Default CORS methods

Methods returned in Access-Control-Allow-Methods unless a pattern has a custom selection.

Method values

These values shape the preflight response; the extension does not block matching requests.

Headers & credentials

Advanced response header behavior, separate from the allowed methods above.

Appearance

Active rules

Add the page you are developing, such as http://localhost:3000. Its requests to any API get relaxed CORS headers. Other websites are not affected unless you turn on "Any site may read" for a rule.

Supported: exact hosts, wildcard subdomains, wildcard schemes, and path patterns ending in /*.
