**CORS Unblocker 0.3.1** prepares the extension for the Chrome Web Store and Firefox Add-ons, and adds real-browser testing for Firefox. There are no changes to how rules behave.

## Chrome Web Store readiness
- **Fewer permissions:** `activeTab` is gone; nothing used it. The extension requests only what it uses: `declarativeNetRequest`, `webRequest`, `storage`, `alarms` and access to sites.
- **Requires Chrome 128 or later.** The "respect server CORS headers" rules rely on a Chrome 128 feature; on older versions Chrome would reject the rules and the extension would silently do nothing. The store now prevents installing it there.
- **New description:** "Fix CORS errors while you develop: see which calls are blocked, then relax CORS headers only for the pages you trust."
- **A privacy policy** ([PRIVACY.md](https://github.com/nevin/cors-unblocker/blob/v0.3.1/PRIVACY.md)) spells out what the extension reads, where it's kept, and for how long. Nothing is ever sent anywhere.
- **Store screenshots** (1280×800) of the real popup, DevTools panel and Settings are in `assets/store/`.
- **Submission guide:** [docs/chrome-web-store.md](https://github.com/nevin/cors-unblocker/blob/v0.3.1/docs/chrome-web-store.md) has the listing text, permission justifications, privacy answers and reviewer instructions, ready to paste.

## Firefox Add-ons readiness
- **The Firefox add-on has its permanent ID: `cors-unblocker@nevin.github.io`** (it was a placeholder). Firefox treats an add-on with a new ID as a different add-on, so a temporary install of an earlier version won't carry its settings over. Export rules first if you need them.
- **Each release now includes the source archive** (`cors-unblocker-source-<version>.zip`), which Firefox Add-ons reviewers require for bundled add-ons. The build is reproducible: two clean builds produce byte-identical files.
- **Submission guide:** [docs/firefox-add-ons.md](https://github.com/nevin/cors-unblocker/blob/v0.3.1/docs/firefox-add-ons.md) has build instructions for reviewers, notes to the reviewer, listing text, categories and privacy answers.

## Firefox tested in a real browser
The Firefox build now runs the same 24 end-to-end cases as Chrome, in real Firefox, in CI and before every release: trusted pages, skip rules, preflights, credentials, exposed headers, blocked-call detection and fixes, pause and resume, the toolbar state, and the welcome page. All passed in Firefox 158 without product changes.

## Fixed
- In the DevTools panel, "Fix all" and per-call "Fix" buttons no longer wrap onto two lines beside a long summary.

## Known limitations
- The popup, DevTools panel and Settings pages are checked with simulated data and automated accessibility checks, but have not been clicked through inside an installed copy as part of the automated tests.

|---|---|---|

| Firefox 140+ | `cors-unblocker-firefox-0.3.1.zip` | Open `about:debugging#/runtime/this-firefox`, **Load Temporary Add-on**, select `manifest.json` |
