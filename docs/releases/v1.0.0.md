**CORS Unblocker 1.0** is the first stable release, ready for the Chrome Web Store and Firefox Add-ons. It adds a reworked Settings page and request-type filters in DevTools. Your rules and settings carry over unchanged.

## New in 1.0

### Settings, reorganised around your rules
- **Unblock one URL from the form.** The add form offers *Trust a page*, *Unblock one URL* (with an "Only from page" field) and *Skip a URL*, each with its own explanation.
- **Grouped, compact rules.** Rules are one line each, grouped under Unblocked calls, Trusted pages, Domain rules and Skipped, with counts and a filter box.
- **Edit in place.** Click Edit, change the pattern (and page, for a call), and press Enter to save or Escape to cancel. Custom methods and opt-ins follow the edited rule. Each rule's methods and "Any site may read" open from its **Options** button.
- **Less noise.** Exact patterns appear on hover and while editing. Requests have **Unblock** and **Skip** buttons in place of icons.
- **Easier to move around.** A compact header and a section menu (Rules, Requests, Behavior, Detection, Responses, Appearance, Backup) stay on screen. Confirmations appear as a short message that's visible wherever you've scrolled.
- **Plainer wording.** For example "This site as an API, for any page" for domain rules, and the scope choice is "Only my rules" or "Every website", with the risk of the latter stated beside it.
- Switching off in Settings now ends any pause, as the popup and DevTools panel already did.

### Filter requests by type in DevTools
The **Requests** tab of the DevTools CORS panel has a filter bar like the Network panel's:
- A filter box with **Invert**.
- Type chips: **All · Fetch/XHR · Doc · CSS · JS · Font · Img · Media · Manifest · Socket · Wasm · Other**. Click one to show only that type, Cmd or Ctrl-click to choose several, All to reset.
- Each request shows its type. "Copy visible" copies exactly the requests shown.

Requests seen before updating are listed under **Other**.

## What 1.0 includes
- **Find blocked calls:** a red count on the toolbar icon, and the reason for each blocked call in the popup and the DevTools panel, even while overrides are off.
- **Fix only what you choose:** unblock single calls (one URL, from one page) or trust a whole page. Every other site keeps normal CORS.
- **Respects working APIs:** responses that already have CORS headers are left alone by default. Credentials, exposed response headers and `Vary: Origin` are handled.
- **Safe by default:** off until you turn it on, a greyed toolbar icon while off, **Pause 1 hour**, and nothing ever leaves your browser ([privacy policy](https://github.com/nevin/cors-unblocker/blob/v1.0.0/PRIVACY.md)).
- **Tested in real browsers:** 53 end-to-end tests run in real Chrome and Firefox on every change and before every release, alongside 97 unit tests. The Firefox build is reproducible from the published source.

## Upgrading
Nothing to do: rules, unblocked calls and settings from 0.3.x keep working. Upgrading from 0.1.x? See the [0.2.0 notes](https://github.com/nevin/cors-unblocker/releases/tag/v0.2.0) for the move to trusted pages.
